MEPERDÍ — THEMEING ACCESIBLE PARA EXPO + TYPESCRIPT
==================================================

Este ejemplo implementa una paleta de marca personalizada con react-native-paper,
cumpliendo la consigna de la actividad: crear una paleta propia y aplicarla al tema.

Incluye además:
- Tema claro y tema de alto contraste.
- Selector global de tema, pensado para permanecer en todas las pantallas.
- Controles para aumentar/disminuir el tamaño del texto.
- Preferencias globales en un contexto React.
- Ejemplo de pantalla y de cómo envolver la navegación.

IMPORTANTE
- Este paquete es una base para integrar en tu proyecto, no una app completa.
- El ejemplo usa react-native-paper v5 y Expo con TypeScript.
- Los botones de tamaño modifican la escala de texto de los componentes que usan
  los estilos/helpers incluidos. No todos los componentes de terceros respetarán
  automáticamente esta escala; hay que aplicarla también en tus pantallas.

1) Instalar dependencias
------------------------
En la raíz del proyecto Expo:

npx expo install react-native-paper react-native-safe-area-context
npx expo install @expo/vector-icons

Si tu proyecto aún no tiene navegación, podés instalar React Navigation:
npx expo install @react-navigation/native
npx expo install @react-navigation/native-stack

2) Copiar archivos
------------------
Copiá la carpeta src/theme, src/contexts y src/components a tu proyecto.
Ajustá las rutas de importación según la estructura que ya tengas.

3) Integrar el proveedor en App.tsx
-----------------------------------
Consultá el ejemplo App.example.tsx. Si ya tenés navegación, NO la reemplaces:
mantené tu navegación y envolvela con <AccessibilityProvider> y <PaperProvider>.
La estructura general debe ser:

<AccessibilityProvider>
  <AppTheme />
</AccessibilityProvider>

AppTheme obtiene el tema del contexto y devuelve:
<PaperProvider theme={theme}>
  {/* tu navegación completa */}
</PaperProvider>

4) Agregar el selector en todas las páginas
-------------------------------------------
La opción más cómoda es poner <AccessibilityToolbar /> en un componente común
de cabecera o en una pantalla de configuración global. Si querés que esté visible
en todas las pantallas, ponelo en el layout compartido o en el header de navegación.
No lo copies de forma independiente en cada pantalla si podés evitarlo.

5) Uso del tamaño de texto
--------------------------
Importá useAccessibility() en cada pantalla y usá fontScale para estilos propios.
Ejemplo:

const { fontScale } = useAccessibility();
const styles = StyleSheet.create({
  title: { fontSize: 24 * fontScale },
  body: { fontSize: 16 * fontScale },
});

En componentes Paper, pasá style={{ fontSize: 16 * fontScale }} cuando corresponda.
No aumentes el tamaño de iconos indiscriminadamente: los iconos tienen un tamaño
propio y conviene mantener objetivos táctiles de al menos unos 44–48 dp.

6) Consideraciones de accesibilidad
-----------------------------------
- Alto contraste usa fondos oscuros y texto claro, con un color de acción amarillo.
- No dependas solo del color para indicar errores o estados.
- Usá etiquetas accesibles y texto explícito en los botones.
- Probá la app con tamaño de fuente grande, TalkBack y un teléfono real.
- El selector global permite cambiar el tema desde cualquier pantalla.
- El tamaño se limita entre 0.85x y 1.6x para evitar que la interfaz se rompa;
  ajustá estos límites según las pruebas con usuarios.

==============================================================================
import React, { createContext, useContext, useMemo, useState } from 'react';
import type { PropsWithChildren } from 'react';

export type AppThemeMode = 'light' | 'highContrast';

type AccessibilityContextValue = {
  themeMode: AppThemeMode;
  toggleHighContrast: () => void;
  fontScale: number;
  increaseFont: () => void;
  decreaseFont: () => void;
  resetFont: () => void;
};

const AccessibilityContext = createContext<AccessibilityContextValue | undefined>(undefined);

const MIN_FONT_SCALE = 0.85;
const MAX_FONT_SCALE = 1.6;
const FONT_STEP = 0.15;

export function AccessibilityProvider({ children }: PropsWithChildren) {
  const [themeMode, setThemeMode] = useState<AppThemeMode>('light');
  const [fontScale, setFontScale] = useState(1);

  const value = useMemo<AccessibilityContextValue>(() => ({
    themeMode,
    toggleHighContrast: () => setThemeMode((current) =>
      current === 'highContrast' ? 'light' : 'highContrast'
    ),
    fontScale,
    increaseFont: () => setFontScale((current) =>
      Math.min(MAX_FONT_SCALE, Number((current + FONT_STEP).toFixed(2)))
    ),
    decreaseFont: () => setFontScale((current) =>
      Math.max(MIN_FONT_SCALE, Number((current - FONT_STEP).toFixed(2)))
    ),
    resetFont: () => setFontScale(1),
  }), [themeMode, fontScale]);

  return (
    <AccessibilityContext.Provider value={value}>
      {children}
    </AccessibilityContext.Provider>
  );
}

export function useAccessibility() {
  const context = useContext(AccessibilityContext);
  if (!context) {
    throw new Error('useAccessibility debe usarse dentro de AccessibilityProvider');
  }
  return context;
}

import React from 'react';
import { View, StyleSheet } from 'react-native';
import { Button, IconButton, Text, useTheme } from 'react-native-paper';
import { useAccessibility } from '../contexts/AccessibilityContext';

type Props = {
  compact?: boolean;
};

/**
 * Barra reutilizable. Colocala en un layout/header común para verla en todas
 * las pantallas, o en una pantalla de configuración si preferís menos elementos.
 */
export function AccessibilityToolbar({ compact = false }: Props) {
  const theme = useTheme();
  const {
    themeMode,
    toggleHighContrast,
    fontScale,
    increaseFont,
    decreaseFont,
    resetFont,
  } = useAccessibility();

  return (
    <View
      style={[
        styles.container,
        { backgroundColor: theme.colors.surface, borderColor: theme.colors.outline },
      ]}
      accessibilityLabel="Opciones de accesibilidad"
    >
      <Button
        mode="outlined"
        icon={themeMode === 'highContrast' ? 'brightness-7' : 'contrast-circle'}
        onPress={toggleHighContrast}
        accessibilityRole="button"
        accessibilityLabel={
          themeMode === 'highContrast'
            ? 'Desactivar alto contraste'
            : 'Activar alto contraste'
        }
        style={styles.themeButton}
        labelStyle={styles.buttonLabel}
      >
        {compact ? (themeMode === 'highContrast' ? 'Contraste normal' : 'Alto contraste') :
          (themeMode === 'highContrast' ? 'Contraste normal' : 'Alto contraste')}
      </Button>

      <View style={styles.fontControls}>
        <IconButton
          icon="format-font-size-decrease"
          size={24}
          onPress={decreaseFont}
          disabled={fontScale <= 0.85}
          accessibilityRole="button"
          accessibilityLabel="Disminuir tamaño del texto"
        />
        <Text
          variant="labelLarge"
          style={{ color: theme.colors.onSurface, minWidth: 42, textAlign: 'center' }}
          accessibilityLabel={`Tamaño del texto ${Math.round(fontScale * 100)} por ciento`}
        >
          {Math.round(fontScale * 100)}%
        </Text>
        <IconButton
          icon="format-font-size-increase"
          size={24}
          onPress={increaseFont}
          disabled={fontScale >= 1.6}
          accessibilityRole="button"
          accessibilityLabel="Aumentar tamaño del texto"
        />
        <IconButton
          icon="restore"
          size={22}
          onPress={resetFont}
          accessibilityRole="button"
          accessibilityLabel="Restablecer tamaño del texto"
        />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    paddingHorizontal: 8,
    paddingVertical: 6,
    borderBottomWidth: StyleSheet.hairlineWidth,
    gap: 4,
  },
  themeButton: {
    alignSelf: 'flex-start',
    minHeight: 44,
    justifyContent: 'center',
  },
  buttonLabel: {
    fontSize: 16,
    fontWeight: '700',
  },
  fontControls: {
    flexDirection: 'row',
    alignItems: 'center',
    flexWrap: 'wrap',
    minHeight: 48,
  },
});

ARCHIVO: src/components/AppTheme.tsx
==============================================================================
import React from 'react';
import type { PropsWithChildren } from 'react';
import { PaperProvider } from 'react-native-paper';
import { brandHighContrastTheme, brandLightTheme } from '../theme/themes';
import { useAccessibility } from '../contexts/AccessibilityContext';

export function AppTheme({ children }: PropsWithChildren) {
  const { themeMode } = useAccessibility();
  const theme = themeMode === 'highContrast' ? brandHighContrastTheme : brandLightTheme;

  return <PaperProvider theme={theme}>{children}</PaperProvider>;
}

import React from 'react';
import { Text as NativeText, type TextProps, type StyleProp, type TextStyle } from 'react-native';
import { useAccessibility } from '../contexts/AccessibilityContext';

type Props = TextProps & {
  baseFontSize?: number;
  style?: StyleProp<TextStyle>;
};

/** Texto nativo que aplica la escala global elegida por la persona. */
export function AccessibleText({ baseFontSize = 16, style, ...props }: Props) {
  const { fontScale } = useAccessibility();

  return (
    <NativeText
      {...props}
      allowFontScaling
      style={[{ fontSize: baseFontSize * fontScale, color: '#17212B' }, style]}
    />
  );
}

import React from 'react';
import { View, StyleSheet, ScrollView } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import { Button, Text, useTheme } from 'react-native-paper';
import { AccessibilityProvider, useAccessibility } from './src/contexts/AccessibilityContext';
import { AppTheme } from './src/components/AppTheme';
import { AccessibilityToolbar } from './src/components/AccessibilityToolbar';

function ExampleScreen() {
  const theme = useTheme();
  const { fontScale } = useAccessibility();

  return (
    <SafeAreaView style={{ flex: 1, backgroundColor: theme.colors.background }}>
      <ScrollView contentContainerStyle={styles.content}>
        <AccessibilityToolbar />
        <View style={styles.card}>
          <Text
            variant="headlineMedium"
            style={{ color: theme.colors.onBackground, fontSize: 26 * fontScale, fontWeight: 'bold' }}
          >
            MePerdí
          </Text>
          <Text
            style={{ color: theme.colors.onBackground, fontSize: 18 * fontScale, lineHeight: 28 * fontScale }}
          >
            Un botón de ayuda para avisar a tus personas de confianza.
          </Text>
          <Button
            mode="contained"
            icon="lifebuoy"
            onPress={() => {}}
            accessibilityLabel="Pedir ayuda"
            style={styles.helpButton}
            labelStyle={{ fontSize: 20 * fontScale, fontWeight: 'bold' }}
          >
            Pedir ayuda
          </Button>
        </View>
      </ScrollView>
    </SafeAreaView>
  );
}

export default function AppExample() {
  return (
    <AccessibilityProvider>
      <AppTheme>
        <ExampleScreen />
      </AppTheme>
    </AccessibilityProvider>
  );
}

const styles = StyleSheet.create({
  content: { flexGrow: 1, padding: 16, gap: 16 },
  card: { padding: 20, gap: 20 },
  helpButton: { minHeight: 60, justifyContent: 'center' },
});

INTEGRACIÓN EN UNA APP EXISTENTE

Si ya tenés App.tsx y navegación, conservá tu código. Envolvé la raíz así:

import { AccessibilityProvider } from './src/contexts/AccessibilityContext';
import { AppTheme } from './src/components/AppTheme';

export default function App() {
  return (
    <AccessibilityProvider>
      <AppTheme>
        {/* Tu NavigationContainer y tus pantallas actuales */}
      </AppTheme>
    </AccessibilityProvider>
  );
}

Para que la barra aparezca en todas las pantallas, lo ideal es incluir
<AccessibilityToolbar /> en un layout compartido o en un header común. Si usás
React Navigation y querés ponerla en el header, adaptá headerTitle/headerRight o
creá un componente de cabecera propio; no agregues una segunda navegación.

En cada pantalla:
const { fontScale } = useAccessibility();

Luego aplicá fontScale a los tamaños definidos por vos. Ejemplo:
<Text style={{ fontSize: 18 * fontScale, lineHeight: 26 * fontScale }}>
  Texto de ejemplo
</Text>

NOTA: AccessibleText ofrece una forma sencilla para texto nativo, pero su color
por defecto es el del tema claro. En pantallas con alto contraste, pasale el color
explícitamente desde useTheme(). Para componentes Paper, preferí sus variantes
de texto y pasá fontSize escalado en style si necesitás que el control de tamaño
los afecte.
